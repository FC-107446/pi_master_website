The Pi Master Website is basically a project I built so players on my Minecraft Bedrock server can quickly check if it's online and see how many people are playing without having to constantly ask on our group chat. It’s got a green design and it works on phones and computers, and it displays all the latest server rules, news, and screenshots. I coded it using HTML, CSS, and JavaScript for the front end, and it uses a Python Flask API with SQLite and Docker to handle all the backend server data.
