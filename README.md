# Pi Master Website

This is the website for my Minecraft Bedrock server, Pi Master. I made it to give players an easy way to see whether the server is online, check the latest news, and find information about the server.

Website: [https://pi-master.coeus1.tech](https://pi-master.coeus1.tech)

## Features

- **Server status** – Check whether the server is online and see the current player count.
- **Latest news** – Read announcements and updates about the server, including featured articles.
- **Gallery** – Browse screenshots and pictures from the server.
- **Community** – View community-related content.
- **Rules** – Read the server rules before joining.
- **Responsive design** – The website is designed to work on both desktop and mobile devices.

## How it works

The website is built using HTML, CSS and JavaScript, with a Python Flask API handling server data and requests.

It uses:

- **Nginx** to serve the website.
- **Flask** for the API.
- **SQLite** for storing data such as news.
- **Docker** to run the services.

The website and API are hosted on my own server, with HTTPS configured for the public website.

## Project structure

The project is organised into separate files for the website, API and supporting data. The website contains the HTML pages, stylesheets, JavaScript and images, while the API handles things such as server status and news.

## Development

This is an ongoing project, so features and the design may change as I continue working on it.

The main goal is to make it easy for players to find information about Pi Master without having to ask for updates in-game.
