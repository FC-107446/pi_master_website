Server Rules

The rules that help keep Pi Master fair, friendly and enjoyable for everyone.

Server Rules

  • Do not kill another player.
  • Do not rob another player.
  • Do not destroy player-built structures without permission of the owner.
  • Be respectful and kind to one another.
  • No TNT within 100 blocks of another person's base, including the air space within the 100-block radius.
  • No unorganized PvP.
    1. During organized PvP, you may ignore Rule 1.
  • Before building large redstone machines, consult a server admin for permission.
  • No x-ray mods or glitches.

Large Redstone Machines

A large redstone machine can contain many different redstone components. Each component has a redstone value based on how much redstone is needed to craft it.

Redstone Values

  • Redstone dust = 1
  • Redstone torch = 1, because it uses 1 redstone dust.
  • Observer = 2, because it uses 2 redstone dust.
  • Repeater = 3, because it uses 2 redstone torches and 1 redstone dust.

Example

A machine contains:

  • 10 redstone dust
  • 4 redstone torches
  • 3 repeaters
  • 2 observers

Its redstone value is calculated as:

10 + 4 + (3 × 3) + (2 × 2) = 27 redstone

The machine therefore has a redstone value of 27.

Approval Required

A machine that has a redstone value greater than 32 must be approved by a server admin before it is built.
